## Selected Projects

### Prime Motors

A PHP and MySQL automobile dealership system designed to centralize dealership sales and workshop operations.

Key features include:

- Role-Based Access Control
- Customer Directory
- Vehicle Inventory
- Sales Transactions
- Service Tickets
- Mechanic Assignments
- Invoice Generation
- ACID Transaction Handling
- Audit Logging

### PUP-Based Grades Calculator

A Java-based application designed around the grading system of the Polytechnic University of the Philippines.

The system automates weighted grade calculations and academic standing assessment using structured application logic and UML-based system design.

### Think Blink

An Arduino and C++ interactive memory game inspired by sequence-based memory challenges.

The prototype uses:

- LED sequence generation
- 16x2 LCD feedback
- Arduino hardware
- C++ backend logic
- Real-time player interaction

### BigBro — All-In Billing System

A COBOL-based billing system designed for MSME operations.

The project includes:

- User authentication
- Inventory deduction
- Automated calculations
- Billing workflows
- Console-based interaction
- Software quality considerations based on ISO/IEC 25010
